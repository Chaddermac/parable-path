# Premium Holiday globes

Eight decorative shells were generated using the supplied Holiday Edition Snow Globes Collection as a material/atmosphere reference, never as an icon source. No movie-character artwork is used. Final transparent PNGs serve server exports; optimized WebPs serve the website. Shared mapping lives in `lib/holiday/globes.ts`. Card cache version: `winter-10` (supersedes the older handoff version).

Official files in `public/holiday/artwork` are untouched. `scripts/build-holiday-globes.mjs` mechanically isolates their white foreground glyphs, preserving their geometry, then composites them into the decorative scenes and applies a shared eight-point satin-gold base seal. Hashes, sizes, placement and derivation are recorded in `provenance.json`.

Original generated shells are retained in `/Users/chadmcswain/Documents/Codex/ParablePath-output/premium-globes/<id>.png`. Rebuild with `node scripts/build-holiday-globes.mjs /absolute/path/to/shells`.

Generation recipe: one isolated premium collectible snow globe on transparent square canvas; circular dimensional clear-glass dome, edge thickness, restrained refraction and upper-left highlights; sparse suspended snow; empty upper-middle interior reserved for an application-owned white symbol; brushed gold base and soft shadow. No letters, logos, symbols or character art. Reference is used only for materials and construction. Per-type atmosphere: green welcoming winter clearing; teal water and distant hills; restorative blue snow hills; deep-blue ascending steps; violet possibility glow and stars; cranberry winter botanicals; orange winding dawn path; amber sunrise horizon. Icons are composited deterministically, not generated by AI.

Website assets are 512×512 WebP, under 65 KB each; export assets are 768×768 transparent PNG. Only requested result globes are loaded by the image route. No new animation, analytics, scoring or assessment changes are introduced.
